# Product FAQ

## Team workspaces

Team workspaces let members share projects, comments, and files. An administrator can invite members from Settings > Team.

## Notifications

Notification preferences are available under Settings > Notifications. You can control email alerts, browser notifications, and weekly summaries.

## Data export

Workspace administrators can export project data from Settings > Data export. The export is delivered as a ZIP file containing CSV records and attachments.

## Integrations

The product supports Slack and Google Calendar integrations. Administrators can connect them from Settings > Integrations and revoke access from the same page.

## Workspace roles

Workspace roles include Administrator, Member, and Guest. Administrators manage billing, integrations, invitations, and exports. Members can work on projects shared with them. Guests have limited access to specifically shared projects.

## Project permissions

Project owners can change a project between private and shared visibility. A private project is visible only to invited members. Removing a member from a project also removes access to its comments and files.

## Search and archives

Use the search box in the top navigation to search project names, tasks, comments, and file names. Archived projects are hidden from the active project list but remain searchable by administrators.

## File limits

Individual uploads can be up to 100 MB. Supported common file types include PDF, DOCX, XLSX, PNG, and JPG. Uploads that exceed the limit should be compressed before being added to a project.

## Mobile access

The web application is responsive on modern mobile browsers. Push notifications require browser permission and can be enabled from Settings > Notifications.
